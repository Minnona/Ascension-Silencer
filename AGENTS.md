# Project instructions

- WoW Ascension / 3.3.5-compatible addon.
- Do not use modern retail-only WoW APIs.
- Modify existing modules instead of creating new ones unless functionality is genuinely separate.
- Keep SavedVariables backward compatible.
- Never whitelist whole spam messages; use scoring/rules.
- Run syntax/static checks before committing.
- Do not commit directly to main.
- Use feature branches.
